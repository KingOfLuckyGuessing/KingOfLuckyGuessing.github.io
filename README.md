# Portfolio Website

A simple, dependency-free portfolio website hosted on GitHub Pages.

## View it live

https://kingofluckyguessing.github.io

## Adding your real projects

The `Projects` section in `index.html` currently has three template cards.
To showcase a real project:

1. Copy one of the `<article class="card">` blocks.
2. Replace the title, description, and tags.
3. Point the "View Project →" link at the project's URL.
4. Commit and push — the site updates automatically.

## Files

- `index.html` — page structure and content
- `styles.css` — all styling (no frameworks, no build step)
- `.nojekyll` — tells GitHub Pages to serve the files exactly as-is
