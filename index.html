CardialSync — Cardiac MRI Time Synchronization

Web application built with UT Southwestern Medical Center that uses the CircAdapt model and a time-synchronization algorithm to align pressure and volume data for accurate PV-loop analysis in children with congenital heart disease. The MATLAB computational core is compiled into a Docker microservice behind a Nuxt frontend.
